# Portfolio Profesional

Bienvenido a mi portfolio web profesional.

Este proyecto funciona tanto como mi carta de presentación digital como un laboratorio activo de desarrollo, donde aplico, consolido y documento los conocimientos adquiridos durante mi formación en Desarrollo de Aplicaciones Web (DAW), mis proyectos personales y mi experiencia profesional previa en el sector IT.

Mi objetivo es construir una plataforma viva que refleje mi evolución técnica, reúna mis proyectos más relevantes y muestre soluciones reales desarrolladas mediante tecnologías modernas de frontend, backend, bases de datos e infraestructura.

---

## Objetivos

* Mostrar mis proyectos y experiencia técnica.
* Documentar mi aprendizaje y evolución profesional.
* Aplicar buenas prácticas de desarrollo y arquitectura de software.
* Experimentar con nuevas tecnologías y herramientas.
* Mantener un repositorio vivo y en constante evolución.

Proyecto final de DAW.

Aplicación de gestión para clínicas dentales desarrollada con Angular, Symfony y PostgreSQL, enfocada en la gestión de pacientes, agenda médica, documentación clínica y seguridad de los datos.

## Estrategia Git

El proyecto sigue una estrategia de ramas basada en Git Flow simplificado:

* `main` → Producción
* `develop` → Integración
* `feature/*` → Nuevas funcionalidades
* `fix/*` → Corrección de errores
* `docs/*` → Documentación
